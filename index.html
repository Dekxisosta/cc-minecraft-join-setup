Before you start

  • A Windows 10 or 11 PC with administrator access, or a Mac or Linux computer where you can use sudo.
  • Minecraft Java Edition.
  • The setup files for your system: Join-MinecraftNetwork.bat and .ps1 on Windows, or join-minecraft-network.sh on macOS and Linux. Download them in the next section, or use the zip from the host.
  • The Tailscale auth key from the Discord server. It starts with tskey-. You paste it during setup.
  • The zip extracted to a local drive such as C:\Temp, with both files in the same folder. Running from inside the zip or from a mapped or network drive fails.

Set up the connection

Get your auth key first

The auth key is in the Discord server. Copy it before you start, because the setup asks you to paste it.

Windows only: unblock the files (once)

No scripts needed. You install Tailscale yourself, then connect it with the auth key from the Discord server.

  1. Install Tailscale

    Windows and Mac: download it from tailscale.com/download and run the installer. If the app asks you to sign in, close that window. You connect with the auth key instead. Linux: run this in a terminal.

  2. Connect with the auth key

    Open a terminal and run the command for your system. Replace PASTE_KEY_HERE with the key from the Discord server. On Windows, open PowerShell as administrator first.

    If this computer is already signed in to a different Tailscale network, add --force-reauth to the end of the command. That disconnects you from the other network.

  3. Check the connection

    Windows should print TcpTestSucceeded : True. On macOS and Linux, a successful check ends with succeeded or open.

  4. Join in Minecraft

    Continue with Join in Minecraft below. Copy the server address from that box, because nothing copies it for you here.

Join in Minecraft

  1. Open Multiplayer

    Start Minecraft Java Edition and click Multiplayer.

  2. Add the server

    Click Add Server (or Direct Connection) and paste the address into Server Address with Ctrl+V.

  3. Join

    Click Done, then double-click the server.

You only run the setup once. Running it again is safe: it skips anything already done. Tailscale reconnects on its own afterward. If you can’t connect later, run the setup again.

What you’ll see

The setup runs in five stages and shows a progress bar for each wait.

  • 1/5Checking system: administrator rights.
  • 2/5Installing Tailscale: download, signature check, silent install. Skipped if already installed.
  • 3/5Starting the Tailscale service.
  • 4/5Joining the private network. Skipped if you are already connected to it. If you are on a different Tailscale account, it asks before switching.
  • 5/5Testing the Minecraft server, up to five attempts.

If anything fails, the window stays open, shows the error in red, and saves it to %TEMP%\join-minecraft.log.

Fix problems

ProblemFix
Window closes immediatelyExtract the zip and keep both files in one local folder. If it still closes, use the PowerShell method.
“These files can’t be opened” or “Your Internet security settings prevented…”Windows marked the downloaded files as blocked. Run the Unblock-File command in the download box, or right-click each file, choose Properties, tick Unblock, and click OK. Then try again.
Windows or antivirus blocks the fileClick More info, then Run anyway, or allow the file in your antivirus.
“Running scripts is disabled on this system”Use the PowerShell method with the -ExecutionPolicy Bypass command.
“The file is not digitally signed”Run Unblock-File .\Join-MinecraftNetwork.ps1, then try again.
“No valid auth key entered”The key was missing or mistyped. Run the setup again and paste the full key from the host. It starts with tskey-.
“Installer signature invalid”The download was corrupted or intercepted. Run again. If it repeats, tell the host.
“Tailscale service did not start”Restart your PC and run again, or run Start-Service Tailscale in an administrator PowerShell.
“Tailscale failed to connect”The key may be expired, used up, or revoked. Ask in the Discord server for a new one. If you use Tailscale with another account, sign out of it first.
Connected, but “server not reachable”The server may be offline. Ask the host, wait a minute, and run again.
“Switch this PC to the Minecraft network?”This computer is already signed in to a different Tailscale account, or the server is offline. Answer Y to switch (you will be signed out of the other network and paste the key from the Discord server). Answer N to change nothing.
macOS or Linux: “Permission denied”Run it with bash join-minecraft-network.sh instead of opening it directly.
macOS: “Install Tailscale from…”Homebrew isn’t installed. Install Tailscale from tailscale.com/download, open it once, then run the script again.
“tailscale is not recognized” or “command not found”Open a new terminal window after installing, or use the full path shown in the “Install it yourself” tab.
“changing settings via ‘tailscale up’ requires mentioning all non-default flags”Add --reset to the command. The setup scripts already do this.
Anything elseSend the host %TEMP%\join-minecraft.log. Paste that path into File Explorer to open it.
